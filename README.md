# Подсчет количества уникальных элементов массива

## Постановка задачи

Дан целочисленный массив фиксированного размера (10 элементов).  
Требуется определить количество элементов, которые встречаются в массиве ровно один раз.  
Массив задаётся в коде программы (хардкод).  
Результат (количество уникальных элементов) выводится на экран.
